# React + Vite

This template provides a minimal setup to get React working in Vite with HMR and some ESLint rules.

Currently, two official plugins are available:

- [@vitejs/plugin-react](https://github.com/vitejs/vite-plugin-react/blob/main/packages/plugin-react) uses [Babel](https://babeljs.io/) (or [oxc](https://oxc.rs) when used in [rolldown-vite](https://vite.dev/guide/rolldown)) for Fast Refresh
- [@vitejs/plugin-react-swc](https://github.com/vitejs/vite-plugin-react/blob/main/packages/plugin-react-swc) uses [SWC](https://swc.rs/) for Fast Refresh

## React Compiler

The React Compiler is not enabled on this template because of its impact on dev & build performances. To add it, see [this documentation](https://react.dev/learn/react-compiler/installation).

## Expanding the ESLint configuration

If you are developing a production application, we recommend using TypeScript with type-aware lint rules enabled. Check out the [TS template](https://github.com/vitejs/vite/tree/main/packages/create-vite/template-react-ts) for information on how to integrate TypeScript and [`typescript-eslint`](https://typescript-eslint.io) in your project.

# 🔐 PassOP – Password Manager & Protector  

![PassOP Screenshot](./Screenshot.png)

PassOP is a simple and secure **password manager** built using **React.js** that helps you manage all your website credentials safely and conveniently.  
It’s designed with a clean, modern UI and includes essential features like saving, editing, deleting, and copying passwords — all handled securely on your local device.

---

## 🚀 Features

- 🧩 **Add & Save Credentials** – Quickly save your website, username, and password.  
- 👁️ **Password Visibility Toggle** – Show or hide passwords as needed.  
- 📋 **Copy to Clipboard** – Copy any password instantly with one click.  
- ✏️ **Edit & Delete** – Update or remove credentials easily.  
- 💾 **Persistent Local Storage** – Data remains saved even after refreshing or closing the browser.  
- 🖥️ **Responsive & Modern UI** – Clean interface that adapts to all screen sizes.  
- 🔒 **Privacy Focused** – All passwords are stored securely in your browser’s local storage (no cloud storage).

---

## 🛠️ Tech Stack

| Category | Technologies Used |
|-----------|-------------------|
| **Frontend** | React.js |
| **Styling** | CSS3 / TailwindCSS |
| **Storage** | Browser LocalStorage |
| **Libraries** | React Toastify, UUID, Lucide Icons (or FontAwesome) |
